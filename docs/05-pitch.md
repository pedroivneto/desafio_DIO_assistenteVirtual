# Pitch (3 minutos)

### 1. O Problema (30 seg)

```
Dúvidas gerais sobre finanças, como traças planos de ação para investimento, quitação de dividas, etc.
```

### 2. A Solução (1 min)

```
Com uma base de dados robusta, ele consegue trazer respostas diretas e empáticas, de forma contemporânea e descontraída.
```

### 3. Demonstração (1 min)

Pela falta de GPU da máquina, o processamento, tanto da gravação quanto do agente, ficou a cargo da CPU, deixando o processo lento, logo a demonstração final no vídeo foi com uma situação fictícia juntamente com o resultado final.

### 4. Diferencial e Impacto (30 seg)

Por ter uma base fechada, a segurança das informações repassadas é o principal fator (sempre lembrando ao usuário que para uma melhor consultoria, deve-se procurar um profissional da área), e todos os dados são fornecidos pelo próprio usuário, este devendo fornecer informações ólidas para uma melhor resposta.
